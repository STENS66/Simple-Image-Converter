## Description

**Simple Image Converter** is a simple and secure application that allows you to convert your image files and documents quickly and efficiently. It works only locally on the user's computer, ensuring maximum security and absolute privacy for your data.

## Preview

![Screenshot of the Simple-Image-Converter app](https://github.com/STENS66/Simple-Image-Converter/blob/main/images/Simple-Image-Converter-en.png?raw=true)

### Compatibility

Desktop application designed for:

* **Windows**: 10 and 11 (64-bit).
* **Linux**: Available via Snap package on **Ubuntu** and compatible distributions.

### Features

* **The user interface is user-friendly** and easy to use, allowing any user to convert images effortlessly.

* **Multilingual Support:** The application is available in 7 languages: **English**, **French**, **German**, **Spanish**, **Italian**, **Portuguese (BR)**, and **Japanese**.

* **Supports multiple** output formats, including **PDF**, **PNG**, **JPG**, **JPEG**, **WEBP**, **ICO**, **BMP**, **GIF**, and **TIFF**.

* **Also allows the conversion of .SVG files** to PDF, PNG, JPG, JPEG, WEBP, ICO, BMP, GIF, and TIFF formats.

* The application **does not support the conversion** of PDF, PNG, JPG, JPEG, WEBP, ICO, BMP, GIF, and TIFF files **to .SVG format**.

* **Support for converting XPS and OXPS files** to PDF, PNG, JPG, JPEG, WEBP, ICO, BMP, GIF, and TIFF formats. For GIF and TIFF formats, a single multi-page file is generated. For other image formats, one file is created per page of the original document.

* **Dynamic Image Resizing:** Quickly resize your images on the fly during the conversion process using a simple, integrated toggle.

* **Automatic Custom Suffix:** Instantly identify your processed files by automatically appending a _SIC (Simple Image Converter) suffix to all converted files.

* **PDF compression options:** When converting to PDF format, you can choose from different compression levels (Maximum Quality, Light, Medium, Strong) to optimize the size of your documents.

* **Image quality options (JPG, JPEG, WEBP):** When converting to these formats, you can select a quality level (Maximum Quality, High, Medium, Low) to adjust the compression ratio and output file size.

* **Smart Compression Analytics:** The post-conversion summary calculates and displays the exact storage space saved or lost for each batch.

* **Multiple files can be converted at the same time.**

* **"Safe-by-Default" Data Protection:** Original files are never overwritten. If a file with the same name already exists in the output folder, the application automatically applies a smart incremental numbering system (e.g., _1, _2).

* **Detailed logging:** An app.log file is created and overwritten each time the application runs, recording operations and any errors. This log can be viewed at any time via a dedicated button in the graphical interface and is essential for diagnosis in case of problems. For faster bug fixes or troubleshooting, this file can be sent to support at app.sencie@gmail.com.


## Usage

**To convert images with "Simple Image Converter":**

* Select a source folder containing the images and documents to be converted. (Ensure only supported files are present in this folder for optimal conversion).

* Select an output folder where the converted files will be saved.

* Choose the desired output format from the available options.

* If you are converting to **PDF**, **JPG**, **JPEG**, or **WEBP**, select the desired compression level. You can also **enable dynamic resizing or the _SIC suffix** at this stage.

* Click the "Convert Images" button to launch the conversion.

* The converted files will be saved in the specified output folder.

* In case of a problem, you can click "View Log File" in the "Developer" section and send us this file to facilitate technical support.

## On Linux (Ubuntu/Snap)

**Plug & Play Experience**: The Linux version (Snap) is a **strictly confined**, all-in-one package.

⚠️ **Note regarding external drives (USB/SD)**: Since the application runs in a secured environment, it cannot access your external drives by default. If your files are stored on a USB flash drive or a second hard drive, you must grant access by running this command once in your terminal:


```
sudo snap connect simple-image-converter:removable-media
```
